# Legacy 兼容版第三方依赖说明

## SQLite

交付包当前使用的离线依赖：

- `Stub.System.Data.SQLite.Core.NetFramework.1.0.118.0`

用途：

- 为 `GatewayDemo.Legacy.Web` 提供 `System.Data.SQLite.dll`
- 提供 `x86/x64 SQLite.Interop.dll`

## 版权说明

当前交付包没有额外引入商业收费第三方组件。

SQLite 相关依赖仅用于网关自有库的本地存储能力，便于客户在不安装 SQL Server 的情况下直接运行。

如果后续客户要求统一切到 `SQL Server 2005+`，可以使用：

- `sql/legacy/GatewayDemo.SqlServer2005.sql`

## ARR / URL Rewrite

这份兼容版默认不强依赖 ARR。

原因：

- 当前交付目标优先降低部署成本
- 客户环境很多是离线环境
- 自包含代理更适合作为首次交付形态

如果客户后续明确希望统一使用 IIS 成熟代理组件，再补 `ARR / URL Rewrite` 安装包和站点规则即可。

## APP 与安全实现

兼容版当前没有额外引入新的商业收费安全组件。

这里说的 APP 设备凭据实现，指的是仓库里保留的**自定义 APP 接入协议**。它当前属于可选增强项，不是“现有官方 APP 套网关”这条主线的唯一实现方式。

这套可选增强能力使用：

- `.NET Framework` 自带的 `System.Security.Cryptography`
- 机器级 `DPAPI (LocalMachine)` 保护已签发的 APP secret
- SQLite 本地表保存防重放 nonce

这样做的目的是在 `VS2019 + net472 + 离线环境` 下保持实现闭环，同时不额外增加部署成本。
