# 快普体验站联调说明

当前源码默认已将 `erp-main` 指向快普易系列体验站：

- 体验站地址：`https://j.kuaipu.com.cn:2027/`
- 代理入口：`/proxy/erp-main/default.aspx`
- 当前配置文件：`src/GatewayDemo.Legacy.Web/App_Data/gateway-sites.json`

## Profile 切换

当前支持两种上游 profile：

| Profile | 上游地址 | 用途 |
|---------|----------|------|
| `experience` | `https://j.kuaipu.com.cn:2027/` | 公网体验站联调（默认） |
| `local-demo` | 自定义（需指定 `-DemoBaseUrl`） | 本地演示站联调 |

切换命令：

```powershell
# 切换到公网体验站
powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 -Profile experience

# 切换到本地演示站
powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 -Profile local-demo -DemoBaseUrl http://localhost:80/
```

本地演示站详细接入步骤见 [本地演示站接入说明.md](./本地演示站接入说明.md)。

当前 APP 相关口径按仓库根目录的 [需求边界说明.md](../../需求边界说明.md) 执行：

- 主需求：给现有官方 APP 套网关
- 次需求：浏览器和 APP 都走统一认证
- 非当前主需求：开放给第三方 APP 的自定义接入协议

## 已验证通过的链路

1. 浏览器访问 `http://localhost:5050/proxy/erp-main/default.aspx`
2. 网关拦截未授权设备，进入申请页
3. 管理后台审批放行
4. 通过网关进入体验站登录页
5. 登录页图片、CSS、JS、验证码图片均可经代理返回 `200`
6. 真实登录链路可继续走通：
   - `/default.aspx`
   - `POST /User/PCLogin`
   - `302 -> /ashx/winCheck.ashx`
   - `/WebEnterprise/newmain.aspx`
7. 登录后的主页面标题已验证为 `易整合管理平台`

## 体验站登录特征

- 登录页根路径就是 `/default.aspx`
- 账套编号对应 `ddlDataCenter=001`
- 登录并非纯表单提交，而是前端脚本先调用 `User/PCLogin`
- 登录成功后会先进入 `ashx/winCheck.ashx`，再自动打开 `/WebEnterprise/newmain.aspx`
- 如果浏览器拦截弹窗，需要允许该站点弹窗

## 资源路径特征

体验站页面里同时存在这几类资源路径：

- 相对路径：`Resource/...`
- 根路径：`/Resource/...`
- 上级相对路径：`../Resource/...`
- ASP.NET 资源：`/ScriptResource.axd`

当前网关代码已按以上真实结构做过联调验证。

需要额外说明的是：

- 这份联调说明里优先覆盖的是浏览器侧体验站链路
- 现有官方 APP 的主目标是“只改服务器地址，让原有链路经过网关”
- 后台里的 `AppKey / AppSecret / HMAC` 页面只作为后续可选增强项保留
