# 本地演示站接入说明

本文档面向"本地演示站点 + legacy 兼容网关"的真实落地路径。
文档默认读者是能在 Windows 服务器上执行 IIS / SQL Server 操作的工程师。

---

## 1. 本地演示站包关键组成

演示站点包来自研发提供的 `演示站点20260330`，解压后包含以下部分：

### 1.1 Web 站点

- 路径：`演示站点20260330\演示站点20260330\web\701日构建20260330\`
- 技术：ASP.NET / .NET Framework 4.7.2 / Web Forms / DevExpress
- 配置：`web\kpweb.config` 中定义数据库连接

### 1.2 数据库备份

- 路径：`演示站点20260330\演示站点20260330\数据库\`
- `7E2088-20260330.bak`：主库

### 1.3 KpScheduleService

- 路径：`演示站点20260330\演示站点20260330\KpService\`
- 主程序：`KpScheduleService.exe`
- 安装脚本：`install.bat`（使用 `InstallUtil.exe` 注册 Windows 服务）

- 配置文件：`KpScheduleService.exe.config`

- Sentinel 驱动安装：`Sentinel_LDK_Run-time_setup_7.10（支持2022）\` 或 `7.9.0\`
- 取指纹 / 导入授权：`RUS_7.6.exe`

## 2. 从配置中确认的关键事实

| 项目 | 值 | 来源 |
|------|------|------|
| 主库名 | `7E2088` | `kpweb.config` -> `Initial Catalog=7E2088` |
| 数据库登录 | `KPMIS` / `KPM6admin_` | `kpweb.config` -> `User ID` / `Password` |

## 3. 正确的推进顺序

### 阶段 1：部署并验证原始演示站点

**必须先完成此阶段，再进入阶段 2。**

1. 安装 SQL Server Express 2016+（本机已有安装器：`packages\sqlserver\`）
2. 恢复数据库：
   - `7E2088`（主库）
   - `7E2088_Annex`（附件库）
3. 确认 SQL Server 登录 `KPMIS` 可用，或按备份实际需要创建
4. 部署 Web 站点到 IIS：
   - 指向 `web\701日构建20260330\` 目录
   - 绑定一个本地端口（如 `80` 或 `8080`）
   - 应用程序池设为 `.NET Framework v4.0` / `Integrated`
5. 安装 Sentinel 驱动（如果尚未安装）
6. 运行 `部署软狗.bat`
7. 导入 V2C 授权（如已有）
8. 安装并启动 `KpScheduleService`：
   - 以管理员身份运行 `KpService\install.bat`
9. 验证原站点可访问：
   - `http://localhost:<端口>/default.aspx` 应显示登录页

**阶段 1 验证项：**
- [ ] 浏览器直接访问 `http://localhost:<端口>/default.aspx` 能正常显示登录页
- [ ] 登录页样式、验证码图片正常加载
- [ ] 可使用测试账号登录并进入 `newmain.aspx` 主界面
- [ ] `KpScheduleService` 服务处于 Running 状态

### 阶段 2：切换 legacy 网关上游到本地演示站

确认阶段 1 通过后：

1. 部署 legacy 网关到 IIS：
   - 将 `src\GatewayDemo.Legacy.Web` 作为独立站点
   - 绑定 `5050`（业务）和 `5051`（管理）
   - 或使用 `scripts\legacy\setup-demo-sites.ps1`
2. 切换 profile 到本地演示站：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 `
       -Profile local-demo `
       -DemoBaseUrl http://localhost:<演示站端口>/
   ```
3. 确认 `gateway-sites.json` 已更新
4. 运行前置���查确认：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\legacy\check-local-demo-prereqs.ps1
   ```

**阶段 2 验证项：**
- [ ] `http://localhost:5050/gateway` 网关首页正常
- [ ] `http://localhost:5050/proxy/erp-main/default.aspx` 经网关代理显示登录页
- [ ] 网关管理后台 `http://localhost:5051/admin` 可访问
- [ ] 浏览器设备申请 -> 审批 -> 放行链路正常
- [ ] 审批后经代理访问登录页、登录、进入主界面正常

### 阶段 3：官方 APP 回归

1. 在手机/模拟器上配置网关地址为 `http://<网关IP>:5050`
2. 验证 APP 初始化流程：
   - `sys.ashx?action=fileversion` 返回版本信息
   - `sys.ashx?action=tenant_name` 返回企业名称
3. 验证 APP 登录流程
4. 验证 APP 日常操作是否经网关正常代理

## 4. Profile 切换操作

legacy 网关通过 profile 机制管理上游配置，不需要手工编辑 JSON。

### 切换到公网体验站

```powershell
powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 -Profile experience
```

### 切换到本地演示站

```powershell
powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 `
    -Profile local-demo `
    -DemoBaseUrl http://localhost:80/
```

`-DemoBaseUrl` 需要替换为本地演示站实��地址和端口。

运行前置检查脚本即可查看：

## 7. 已知边界项

### 7.1 WebSocket / 消息推送

- legacy managed proxy 不支持 WebSocket 透明代理
- 如果演示站有消息推送功能，推送链路可能无法经网关正常工作
- 最小可落地方案：
  - 使用 `IIS ARR + URL Rewrite` 替代 managed proxy 承担 WebSocket 代理
  - 或升级到现代版 `.NET 10` 网关

### 7.2 HTTPS

- 当前本地环境默认按 HTTP 部署
- 如需 HTTPS，需在 IIS 层面绑定证书

### 7.3 跨域与弹窗

- 登录成功后会通过 `winCheck.ashx` 弹窗打开主界面
- 浏览器可能拦截弹窗，需手动允许

## 8. Repo 内 vs 管理员动作分类

### Repo 内可完成（无需管理员 / 不依赖 IIS / SQL）

- 配置 profile 模板文件
- 运行 `set-gateway-profile.ps1` 切换上游
- 运行 `check-local-demo-prereqs.ps1` 检查前置条件
- 修改 `gateway-sites.json` / `Web.config` 等配置
- 构建和打包 legacy 网关
- 更新文档

### 需要管理员 / 系统级操作

- 安装 SQL Server Express
- 恢复数据库（`RESTORE DATABASE` 命令）
- 创建 SQL Server 登录和用户
- 启用 IIS 角色和 ASP.NET 4.x 模块
- 在 IIS 中创建站点
- 注册 ASP.NET：`aspnet_regiis -ir`
- 安装 Sentinel 驱动
- 运行 `部署软狗.bat`
- 导入 V2C 授权
- 使用 `InstallUtil.exe` 安装 `KpScheduleService` Windows 服务
- 启动/停止 Windows 服务
