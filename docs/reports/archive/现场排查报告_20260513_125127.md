## 一、问题诊断

### 1. 原始问题
研发反馈的问题：
- ❌ 配置的 IP 地址 10.188.188.249 无法访问
- ⚠️ 移动端请求报 302 错误
- ❓ 不确定 HostNames、白名单等功能是否实现

### 2. 根本原因
**IP 地址配置错误**：
- 配置文件中使用了 10.188.188.249:15050 和 10.188.188.249:15051
- 但本机实际 IP 地址为：
  - 172.26.116.77 (WLAN)
  - 172.17.69.159 (VirtualNet)
  - 192.168.208.1 (WSL)
- 导致通过 10.188.188.249 访问时无法匹配 HostNames 配置

### 3. 302 重定向说明
**这是正常的安全行为**：
- 未授权设备访问受保护资源 → 302 重定向到审批页面
- 上游 mock 服务未登录访问 → 302 重定向到登录页面
- 这不是 bug，而是网关的核心功能

## 五、移动端集成说明

### 移动端发起审批时的参数
POST 请求需要包含以下参数（Form 或 JSON）：
- **UrlBefore**: 原始访问地址
- **UserId**: 用户账号
- **DataCenterId**: 数据中心 ID
- **DeviceImei**: 设备 IMEI
- **MobileUserNum**: 移动用户编号

这些参数会自动存储到 \GatewayAccessRequests\ 表的对应字段：
- LegacyUrlBefore
- LegacyUserId
- LegacyDataCenterId
- LegacyDeviceImei
- LegacyMobileUserNum

外部审批系统可以直接查询这些字段进行审批。

## 六、常见问题

### Q1: 为什么访问时总是 302？
A: 这是正常的安全行为。未授权设备首次访问会重定向到审批页面。审批通过后才能正常访问。

### Q2: 如何测试白名单路径？
A: 白名单路径不需要审批即可访问。例如：
- /sys.ashx?action=fileversion
- /datacenter/getdatacenterinfo

### Q3: 如何查看审批记录？
A: 访问管理后台：http://localhost:5051/Admin/
- 默认账号：gateway-admin
- 默认密码：GatewayDemo!2026

### Q4: 配置修改后不生效？
A: 需要重启 IIS：\iisreset /noforce\
