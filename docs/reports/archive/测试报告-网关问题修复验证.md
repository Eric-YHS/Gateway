**原因**: IIS 站点当前只绑定了端口 5050 和 5051，没有绑定端口 15050

**解决方案** (如果需要通过 15050 访问):

1. **方案 1: 添加 IIS 绑定** (推荐)
   ```powershell
   Import-Module WebAdministration
   New-WebBinding -Name "GatewayDemoLegacy" -Protocol "http" -Port 15050 -IPAddress "*"
   ```

2. **方案 2: 使用端口转发**
   ```powershell
   netsh interface portproxy add v4tov4 listenport=15050 listenaddress=0.0.0.0 connectport=5050 connectaddress=127.0.0.1
   ```

3. **方案 3: 直接使用端口 5050**
   - 将所有访问地址从 `15050` 改为 `5050`
   - 这是最简单的方案，不需要额外配置
