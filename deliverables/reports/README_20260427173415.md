# Legacy 网关兼容版 - 交付说明

## 需求边界

当前主需求：

- **主需求**：给现有官方 APP 套网关
- **次需求**：浏览器和 APP 都走统一认证
- 非当前主需求：开放给第三方 APP 的自定义接入协议

## 交付内容

- `GatewayDemo.Legacy.sln` — VS2019 解决方案
- `src/GatewayDemo.Legacy.Web` — 统一认证网关（net472）
- `src/MockBusinessBackend.Legacy.Web` — 本地回归用 mock 后端，可选
- `packages/Stub.System.Data.SQLite.Core.NetFramework.1.0.118.0` — 内置 SQLite
- `scripts/legacy/` — 构建与运维脚本
- `sql/legacy/` — 数据库初始化脚本
- `delivery/legacy/` — 详细文档

交付包已包含编译后的 `bin` 目录，可直接按 IIS 站点方式部署，不需要额外安装数据库。

## 上游 Profile 机制

Legacy 网关支持两种上游 profile：

| Profile | 上游地址 | 用途 |
|---------|----------|------|
| `experience` | `https://j.kuaipu.com.cn:2027/` | 公网体验站联调（默认） |
| `local-demo` | 自定义（需指定 `-DemoBaseUrl`） | 本地演示站联调 |

当前源码默认处于 `experience` profile，即指向快普易系列公网体验站。

## 切换上游 Profile

使用 `scripts/legacy/set-gateway-profile.ps1` 切换：

### 切换到公网体验站

```powershell
powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 -Profile experience
```

### 切换到本地演示站

```powershell
powershell -ExecutionPolicy Bypass -File scripts\legacy\set-gateway-profile.ps1 `
    -Profile local-demo `
    -DemoBaseUrl http://localhost:80/
```

`-DemoBaseUrl` 只接受绝对 `http://` 或 `https://` URL。脚本会自动规范化尾斜杠。

### 示例

| 输入 | 结果 |
|------|------|
| `-Profile local-demo -DemoBaseUrl http://localhost:8080/` | 正常写入 |
| `-Profile local-demo -DemoBaseUrl http://localhost:8080` | 正常写入（自动补尾斜杠） |
| `-Profile local-demo -DemoBaseUrl localhost:8080` | 拒绝（非绝对 URL） |
| `-Profile local-demo -DemoBaseUrl ftp://localhost:8080/` | 拒绝（非 http/https） |

## 前置检查

如果要接本地演示站，可先运行前置检查脚本确认环境就绪：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\legacy\check-local-demo-prereqs.ps1
```

该脚本会检查：IIS、SQL Server、演示站目录、数据库备份、KpService、Sentinel 驱动、.NET Framework、网关配置状态。

如果当前上游仍指向公网体验站，该项会报告 `WARN`，提示尚未切到 local-demo profile。

## 本地演示站接入

如果要对接本地演示站点，**请先阅读** `delivery/legacy/本地演示站接入说明.md`。

该文档包含：

- 正确的推进顺序（先验证原站，再接网关）
- 各阶段的验证项清单
- 已知边界项

## 环境要求

- Windows Server 2008 R2 或更高
- IIS 7.5 或更高
- .NET Framework 4.7.2

## 快速部署

1. 将 `src/GatewayDemo.Legacy.Web` 部署为 IIS 站点，���定端口：
   - `http://服务器地址:5050` — 业务入口
   - `http://服务器地址:5051` — 管理入口
2. 给应用程序池账号增加 `src/GatewayDemo.Legacy.Web/App_Data` 的写权限
3. 访问 `http://服务器地址:5050/proxy/erp-main/default.aspx`

如已安装 IIS，可直接执行建站脚本：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\legacy\setup-demo-sites.ps1
```
